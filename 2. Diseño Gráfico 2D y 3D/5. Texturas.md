- **Tipos de texturas usadas en un material**
	- **Diffuse:**
		- The diffuse map defines the color and pattern of the material in your model. 
		- It’s a lot like taking a picture and applying it to the face of your object. Sometimes this map is labeled as the “color map.” 
		- This usually goes in a slot labeled “texture,” or “diffuse.”
		- Normal map: La dirección en la que apuntan las caras del objeto.
	- **Ambient Occlussion:**
		- An ambient occlusion map is used to calculate how much indirect lighting an object receives.
		- Basically this map is used to calculate the shadows that would be cast by things like the overall ambient lighting in the scene, and also from reflections. 
		- You can use this map to highlight or add detail to your shadows on objects. 
		- Sometimes if using this map in a program without an AO slot, you can overlay this on your diffuse map in a photo editing software to add shadow highlights.
	- **Normal Map:**
		- A normal map is used inside a 3D software to simulate lighting on bumps or dents. 
		- The reason it’s colored is because the x, y, and z information of the map correspond to the RGB value of the bumps and dents. 
		- This is important because the more polygons inside of a rendering, the more computations your computer has to do. 
		- By using a normal map to add bumps, rather than actually adding bumps to yourgeometry, your renderings will run much faster.
	- **Displacement Map:**
		- A normal map is used to add bumps, but a displacement map is instead used to deform the mesh itself. 
		- The normal map simulates movement, but a displacement map actually moves the points inside of your object.
		- This is used for areas where actual shape of mesh is important, but it also comes at a much higher processing and render time cost. 
		- Use sparingly. Generally, there is not a slot for this in real-time rendering programs.
	- **Gloss or Roughness Map:**
		- This map defines the roughness of a surface, which then determines how much light different areas of the surface are going to reflect. 
		- Sometimes these are called roughness maps, and indicate where light should NOT be reflected.
		- If you’re not getting a good result, there’s usually an option for “Invert map” that you can try inside most rendering programs.
